1회차: 앱 화면과 사용자 동작
오늘 진행하는 내용입니다.
- React Native 프로젝트 실행
- 화면을 구성하는 컴포넌트
- 글자와 이미지 표시
- 버튼 클릭 이벤트
- 상태 변경
- 모달 열고 닫기
- 기본적인 스타일 수정
결과물은 버튼을 누르면 안내 모달이 열리는 기본 화면입니다.

2회차: 사진 선택
- 휴대전화 갤러리 또는 카메라에서 사진 가져오기
- 비동기 처리와 async/await
- 선택한 사진을 앱 화면에 표시
- 배열과 객체
- 여러 개의 결과를 목록으로 표시
- 결과 중 하나를 선택
결과물은 학생이 선택한 레고 사진을 화면에 띄우고 임시 후보 목록을 표시하는 앱입니다.

3회차: Brickognize API 연결
- API가 무엇인지 이해 (Application Programming Interface)
- 사진을 API가 받을 수 있는 형식으로 전달
- fetch를 이용한 요청
- Brickognize에서 부품 또는 제품 후보 받기
- 로딩, 성공, 실패 상태 처리
- 인식 후보와 유사도 표시
결과물은 레고 사진을 보내고 부품 또는 제품 후보를 받는 기능입니다.

4회차: Rebrickable API 연결
- 제품 번호를 이용해 제품 정보 요청
- 제품명, 출시 연도, 부품 수 등의 정보 표시
- 제품에 포함된 부품 목록 불러오기
- API 키를 .env에서 관리
- 두 API의 결과 연결
결과물은 인식된 제품 후보를 이용해 상세 제품 정보와 부품 목록을 확인하는 기능입니다.

5회차: 기능 통합과 완성
- 사진 선택부터 결과 표시까지 전체 흐름 연결
- 다시 시도하기와 초기화
- 오류 상황 처리
- 화면 정리
- 실제 휴대전화 테스트
- 학생이 프로젝트 구조와 동작 설명
